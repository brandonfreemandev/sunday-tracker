# Sunday Football — Week 9 Live Tracker

Static live scoreboard for the November 8, 2026 NFL slate, focused on
**New York Jets at Kansas City Chiefs** (Week 9, Arrowhead Stadium).

- Polls ESPN's public scoreboard + summary APIs every 30 seconds.
- Highlights the Chiefs game and flashes a touchdown banner when KC scores.
- No build step, no dependencies — a single `index.html`.

Hosted with GitHub Pages.
